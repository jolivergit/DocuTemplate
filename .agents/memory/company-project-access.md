---
name: Company project access
description: User's access boundary for coworkers sharing a company account.
---

Coworkers should be able to access **only assigned projects**.

**Why:** When asked whether coworkers should access all company projects or only assigned projects, the user chose “Only assigned projects.”

**How to apply:** Preserve this boundary when planning or implementing company membership, project lists, dashboards, related records, and document workflows. Company membership alone must not expose every company project.
